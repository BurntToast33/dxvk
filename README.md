# Left 4 Dead 2 VR - DXVK 2.7.1
A fork of dxvk 2.7.1 modified for l4d2vr based on the modifications made to dxvk by sd805, this branch aims to update the l4d2vr code from DXVK 2.3 to DXVK 2.7.1 while trying to fix bugs and add new features.

# Based on 
* [dxvk_l4d2vr](https://github.com/sd805/dxvk)
* [dxvk 2.7.1](https://github.com/doitsujin/dxvk/tree/v2.7.1)
