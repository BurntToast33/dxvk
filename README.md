# Left 4 Dead 2 VR - DXVK 2.7.1

A fork of [DXVK 2.7.1](https://github.com/doitsujin/dxvk/tree/v2.7.1) by doitsujin for l4d2vr based on the modifications made in [dxvk_l4d2vr](https://github.com/fholger/dxvk_l4d2vr/tree/75167aa2859fe7118ae683e717b97303ad379efa) by fholger and sd805 this branch aims to update the l4d2vr code from DXVK 2.3 to DXVK 2.7.1 while adding new changes.
